# Styling Conventions: Neo-Brutalist Light

The application follows a "Neo-Brutalist Light" or "Soft Tech" aesthetic, characterized by flat geometric containers and structured layouts.

- **Color Palette**: Highly intentional, pastel-heavy palette layered against deep charcoal (`#1C1B1F`) for contrast.
    - Canvas: Peach gradients (`#FCE4D6` to `#FFD9C0`).
    - UI Elements: Pastel accents for metrics (Salmon, Orange, Mint, Lavender).
- **Borders**: All primary UI panels and the navbar use a crisp 1px border with a deep charcoal (`var(--color-ui-charcoal)`).
- **Shadows**: Drop shadows are disabled in favor of flat, geometric structures.
- **Corners**: Hyper-rounded corners, typically `rounded-[24px]` for cards and containers.
- **Typography**: Uses **Plus Jakarta Sans**. 
    - `.ui-heading`: Bold (800), Uppercase, Letter Spacing 0.05em.
    - `.ui-body`: Medium (500), Line Height 1.5.
- **Spacing**: Strictly adheres to an 8pt grid system.
